# Site BMW M

Landing page dedicada à divisão BMW M, com foco em performance, design agressivo e herança motorsport.

## Funcionalidades
- Hero com gradiente dinâmico e tipografia bold
- Cards de modelos M com descrições
- Seção de especificações técnicas
- Timeline da história M
- Footer com links e copyright
- Totalmente responsivo
- Zero dependências externas

## Estrutura de arquivos
- `index.html` — estrutura da página
- `css/style.css` — estilos e animações
- `js/main.js` — animações e interatividade
- `assets/` — imagens e SVGs
- `.gitignore` — logs, node_modules, .DS_Store

## Como rodar localmente
```bash
cd ~/sites/site-bmw-m
python3 -m http.server 8080
# Acesse http://localhost:8080
```

## Deploy
Via Vercel CLI:
```bash
vercel --token <token> --prod
```

## Tecnologias
HTML5, CSS3 (Grid + Flexbox), Vanilla JS, SVG inline

## Créditos
Design original criado por IA. Site demonstrativo, sem afiliação oficial com a BMW AG.
